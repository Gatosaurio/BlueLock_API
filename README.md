# Blue Lock API

API desarrollada con Python y Flask para consultar información
relacionada con personajes del universo Blue Lock.

## Tecnologías
- Python
- Flask
- JSON
- Git y GitHub

## Descripción
Este proyecto permite consultar información mediante endpoints
HTTP que devuelven respuestas JSON. Creado de fan para fans :V, con  bastos conocimientos en  el área de razonamiento, computacional, realista Proactivo, Iterativo, Escalable y Altamente optimizado (Lo primero lo hizo mi profesor, ajjaja)

## Instalación local
1. Clona el repositorio.
2. Crea y activa un entorno virtual.
3. Instala dependencias: `pip install -r requirements.txt`
4. Ejecuta: `python app.py`
